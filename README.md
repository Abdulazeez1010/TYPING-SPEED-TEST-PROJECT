## Overview

### The challenge

Users should be able to:

- View the optimal layout for the interface depending on their device's screen size
- Start a typing test and see live statistics (WPM, accuracy, time)
- Switch between difficulty levels and modes (Timed / Passage)
- Complete a test and view a results summary
- Navigate the entire app using keyboard only
- See clear hover, focus, and active states for all interactive elements

## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties

- CSS Grid

- [Material UI](https://mui.com/) - Component library
- ARIA roles and attributes for accessibility
- LocalStorage for persistent personal bests

### What I learned

This project significantly improved my understanding of accessibility and keyboard interactions in real-world applications.

Key takeaways include:
- Implementing ARIA-correct radio groups with roving tabIndex
- Separating focus, active option, and selected value to avoid keyboard/mouse conflicts
- Managing global keyboard events without breaking native behavior
- Handling mobile typing quirks (virtual keyboards, scrolling, cursor visibility)
- Designing focus styles that match Figma designs without relying on default browser outlines

### Continued development
In future iterations, I'd like to implement the following:
- Multiple test durations (15s, 30s, 60s, 120s)
- Different text categories: quotes, lyrics, code snippets
- Historical tracking of your WPM and accuracy over time
- A keyboard heatmap showing where you make mistakes
- Shareable result cards for social media
